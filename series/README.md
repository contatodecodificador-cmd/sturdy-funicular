# Séries do Contos do Vigia

Cópia de segurança das pastas de cada série (bíblia, roteiro, briefing e desenhos).
Os arquivos de trabalho ficam em `kit/estudio/src/videos/<serie>/`, dentro do kit, que não vai pro Git
(os termos do kit proíbem publicar os arquivos dele). Pra restaurar: copie `series/<serie>/` de volta
pra `kit/estudio/src/videos/<serie>/` e registre a composição em `kit/estudio/src/Root.tsx`.
