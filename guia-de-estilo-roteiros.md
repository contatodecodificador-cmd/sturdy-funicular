# Guia de Estilo dos Roteiros

Fórmula baseada na análise de "How Long Would Your Dog Survive in Every Prehistoric Era?" e da versão espanhola.
Usar a **estrutura e o tom** — nunca copiar texto, fatos na mesma ordem ou imagens de outro canal.

## Estrutura (vídeo de ~15–20 min)

| Bloco | % do vídeo | Função |
|---|---|---|
| 1. Gancho | ~3% | Humor do dia a dia com o personagem → pergunta grande → **loop aberto** (uma promessa que só se paga no final) |
| 2. Personagem + 3 armas | ~5% | Escolher algo "médio/comum" pra ser justo. Dar 3 vantagens concretas. **Uma delas deve pagar no final** |
| 3. Regras / notas | ~3% | Tier list S-A-B-C-D-F + categoria especial abaixo de tudo |
| 4. Etapas (eras, lugares…) | ~80% | 10–15 blocos de ~60–90 s, sempre na mesma fórmula (abaixo) |
| 5. Veredito | ~5% | Tier list completa na tela + **virada emocional** |
| 6. CTA | ~2% | Pergunta pros comentários + gancho do próximo vídeo |

## Fórmula de cada etapa

1. Nome + data/lugar ("O Cambriano, uns 500 milhões de anos atrás")
2. Ambiente: ar, clima, comida
3. **Boa notícia**
4. **Má notícia** — quase sempre um predador com nome, tamanho e um detalhe visual
5. Uma das 3 armas sendo testada
6. (Às vezes) um "fato que quase ninguém sabe" ou um elo com a "família" do personagem
7. Nota seca no final: "**C — algumas semanas.**"

## Tom

- Fala com o espectador: "você", "seu cachorro".
- Frases curtas. Ritmo de conversa.
- Humor seco: "Precisa mesmo que eu explique?"
- Números viram imagem: "como estar no topo de uma montanha", "água de jacuzzi".
- Faça a conta junto com o público: "10 calorias… ele precisa de mil… são cem por dia. Todo. Santo. Dia."
- Quebre expectativas: "Todo mundo acha que é dinossauro. Não é."
- Nomes científicos sempre explicados em uma frase simples.
- Use "uns", "mais de", "cerca de" — números de paleontologia são estimativas.

## Variar as notas

Não deixe as notas subirem em linha reta. Alterne bom e ruim. Guarde o **S** para o fim.

## Localização para o Brasil

- Sistema métrico sempre (kg, m, km/h, °C).
- Referências brasileiras (padaria, calçada, Réveillon, motoqueiro, caramelo).
- Sempre que possível, ancorar em **lugares e fósseis brasileiros** — é o nosso diferencial.

## Visual (instruções para edição)

- Labels discretos com nome do animal/lugar ("PURUSSAURUS — JACARÉ DE MAIS DE 10 M").
- Gráficos simples para dados (barra de oxigênio, comparação de tamanho com o personagem).
- Tier list visível no começo e completa no fim.
- Esqueletos de museu, fósseis reais, reconstruções — usar material com licença (banco de imagens, domínio público, criação própria).

## Checklist antes de gravar

- [ ] Gancho tem loop aberto?
- [ ] Uma das 3 armas paga no final?
- [ ] Toda etapa termina com nota?
- [ ] Notas variam (não sobem em linha reta)?
- [ ] Final tem virada emocional?
- [ ] Todos os nomes científicos conferidos?
- [ ] Todos os números conferidos e com "cerca de/uns"?
- [ ] Nada copiado de outro roteiro?
