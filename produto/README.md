# Estúdio do Nogueira

O produto do **Estúdio do Nogueira**: um método para a pessoa criar o próprio canal de séries
animadas com IA, em partes, em qualquer nicho, com o público votando no caminho da história.
Os canais do dono (o **Contos do Vigia**, de noite, e o **O Tempo Parou**, de dia) entram como modelos,
criações nossas feitas com o mesmo processo. O nome não fica preso a nenhum canal.

## Decisões do dono (07/11/2026)

| Item | Decisão |
|---|---|
| Nome | **Estúdio do Nogueira** (antes: Oficina do Vigia; trocado para não ficar preso a um canal só) |
| O que vai dentro | **Guia**, **skill pro Claude Code** e **personagem-base editável**, vendidos juntos ou separados |
| Preço | só o guia R$ 27, só a skill R$ 47, completo R$ 67 (sugestões) + ofertas extras no checkout |
| Onde vende | **Cakto** |
| Lançamento | **só preparar, sem publicar**. O dono decide a data depois |
| Visual | **Vigia Noturno**: escuro, âmbar de lanterna e verde de medidor (veja `identidade.md`) |

## O que tem nesta pasta

- `identidade.md`: cores, letras e jeito do visual.
- `plano.md`: o sumário do guia, o que a skill faz, os entregáveis e as regras.
- `pagina/index.html`: a página de venda, pronta para subir no Netlify quando o dono quiser.
- `pagina/img/`: as capas reais de O Bunker (parte 1) e de O Tempo Parou (ep. 1).
- `entrega/COMECE-AQUI.md`: o primeiro passo do comprador (contas, GitHub, Claude Code na nuvem, `/comecar`).
- `entrega/estudio/`: os arquivos que o comprador coloca no GitHub (skill, memória do Claude, projeto de vídeo).
- `entrega/extra-ideias/`: o produto extra do checkout, o Caça-Ideias (comando `/ideias`).

## Regras que valem para tudo aqui

1. **Nada do kit nem do guia comprados entra no produto.** Nenhum código, peça, som, texto,
   fonte configurada ou estrutura de capítulos. O código em `series/o-bunker/*.tsx` usa peças do kit
   e **não** pode ser copiado para cá. O que é do dono (ideias, roteiros, personagens) é refeito do zero.
2. **Sem resultado inventado.** Nada de números, depoimentos, prints ou promessa de ganho até existirem
   resultados reais do canal.
3. **Nicho livre:** o terror leve é regra do canal Contos do Vigia, não do produto. A pessoa escolhe o nicho dela.
4. A página sempre avisa que o comprador assina as ferramentas por fora.
5. A página não entrega o método (nada de "10 frases", tags, sincronia, legenda em duas cores).
