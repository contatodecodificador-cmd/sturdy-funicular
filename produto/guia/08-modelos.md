# Modelos para preencher

> Copie, preencha e guarde no seu projeto. Com a skill do Estúdio, o Claude preenche junto com você.

## Perfil do canal (`canal/CANAL.md`)

```
# O meu canal
- Nome do canal:
- Redes:
- Nicho:
- Público:
- Como quem assiste deve se sentir:
- O que nunca entra no canal:
- Quem conta as histórias:
- Jeito de falar:
- Ferramenta de voz e voz escolhida:
- Ritmo de postagem:
```

## Mundo da série (`series/<nome>/MUNDO.md`)

```
# <Nome da série>: o mundo da série
## A série em uma frase
## O que só ela tem (2 ou 3 detalhes)
## Personagens (nome, idade, jeito, marca de longe)
## Regras do mundo (o que pode e o que nunca acontece)
## O detalhe escondido
## O mistério e a resposta
## O plano das partes (uma linha por parte + a escolha + onde os caminhos se juntam)
## Lugares
```

## Ficha de personagem

```
- Nome e idade:
- O que faz:
- Jeito:
- Marca de longe:
- Pele / cabelo / roupa / acessório (com as cores):
- Expressões que a série vai pedir:
```

## Roteiro da parte (`partes/parte-NN/ROTEIRO.md`)

```
# <Série> · parte NN: <título>
Duração: __ s (__ palavras)

## Aberturas
- A:
- B:

## O roteiro
| # | Frase | Cena (cenário, quem, expressão, câmera, o que entra na tela, som) |
|---|---|---|
| 1 | | |

## A escolha: ______ ou ______

## Os dois caminhos
- Opção A:
- Opção B:
- Onde se juntam:
```

## Postagem (`partes/parte-NN/POST.md`)

```
## Legenda (Instagram)
Gancho na primeira linha:
Pedido de voto:
Hashtags:

## Legenda (TikTok)

## Antes de postar
- [ ] Rótulo de IA ligado
- [ ] Capa com título e rosto no miolo

## Ordem
1. Vídeo + capa
2. Stories de chamada
3. Stories da enquete
4. Voltar em 24 h para o resultado
```

## Resultado (`partes/parte-NN/RESULTADO.md`)

```
- Opção A: __%   Opção B: __%
- Venceu:
- Comentários marcantes (sem nome):
- O que muda no plano da série:
```
