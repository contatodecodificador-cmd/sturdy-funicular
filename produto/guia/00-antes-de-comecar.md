# Caderno 0 · Antes de começar

> Neste caderno: as ferramentas, na ordem certa, e o seu projeto aberto no Claude Code na nuvem. Leva uns
> 30 minutos e é feito uma vez só.

## As ferramentas, nesta ordem

1. **Claude Pro (ou superior): o mais importante.** Em claude.ai, assine o Pro. É ele que dá acesso ao
   **Claude Code**, que escreve, desenha e monta os vídeos com você. O plano grátis não tem o Claude Code.
2. **GitHub (grátis).** Em github.com, crie uma conta. É onde os arquivos do seu canal ficam guardados, e
   é por ele que o Claude trabalha na nuvem, **sem precisar de computador potente**.
3. **A voz (comece no grátis).** Crie uma conta numa ferramenta de voz com IA, como o ElevenLabs, para
   testar vozes. Assine um plano pago só quando for postar: é ele que libera o uso comercial.
4. **Remotion:** é a ferramenta que transforma o projeto em vídeo. É grátis para pessoa física e para
   empresa de até 3 pessoas, e o Claude instala sozinho.

## Crie o projeto do seu canal

1. No GitHub, clique em **+** › **New repository**.
2. Dê o nome do seu canal, sem espaços (exemplo: `meu-canal`), marque **Private** e clique em
   **Create repository**.

## Abra no Claude Code, na nuvem

1. Entre em **claude.ai/code**. Atenção: o chat normal do Claude **não** serve.
2. Conecte o GitHub e dê acesso ao repositório que você criou.
3. Escolha o repositório e comece uma sessão.

**Você está no lugar certo** se o nome do seu repositório aparece no topo da conversa.

## O primeiro pedido

Cole na conversa:

```
Este repositório vai ser o meu canal de séries animadas em partes, com vídeos verticais
(1080 x 1920). Prepare um projeto Remotion do zero, instale o que precisar (inclusive as
ferramentas de som e de vídeo), faça um vídeo de teste de 3 segundos e me mostre. Fale
comigo em português simples, uma etapa por vez. Depois, salve as regras de trabalho num
arquivo CLAUDE.md para as próximas conversas.
```

Quando o vídeo de teste aparecer, o seu estúdio está pronto. Siga para o **Caderno 1**.

> **Tem a skill do Estúdio?** Então use o passo a passo da Área (passos 1 a 3): ele já traz o estúdio
> montado, com os comandos, o personagem-base e as ferramentas prontas.

## Deu problema?

| O que aconteceu | O que fazer |
|---|---|
| O Claude diz que não tem repositório | Você está no chat normal. Volte para claude.ai/code. |
| Aparece um pedido para liberar um site | É o Claude pedindo acesso a algo que ele precisa. Leia e aprove. |
| A chave da voz | Nunca cole chave no chat. O Claude abre um cartão seguro para isso. |
